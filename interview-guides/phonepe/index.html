The hiring process

Typically four eliminatory rounds: a take-home-style machine coding round (problem sent, code submitted as a zip), a hard DSA round where you must fully solve at least two of three problems, a fintech-flavored system design round, and a hiring-manager round with senior payments leaders.

RoundFormatWhat's tested
Machine coding~1.5 hr (up to 24 hr window)build a working system, submit as a zip; clean modular code
DSA~60 min3 medium/hard problems; solve at least 2 fully to pass
System design~60 minfintech scenarios (e.g. real-time order feed, payment flows)
Hiring manager~60 minownership, project clarity; often EM plus a payments head

Process and cutoffs vary by drive and change over time — always confirm on the official careers page.

Your prep plan

2-week plan

  • Days 1–4: machine coding practice, building clean modular systems end to end
  • Days 5–9: hard DSA, focused on fully passing all test cases under time
  • Days 10–12: fintech system design (order feeds, payment flows, real-time updates)
  • Day 13: timed machine coding mock
  • Day 14: prepare ownership and project-clarity stories

2-day crash plan

  • Day 1: one full machine-coding build plus 8 medium/hard DSA problems
  • Day 2: one fintech system design mock and behavioral prep

FAQ

How does the machine coding round work?

You get a problem, code a working solution (about 1.5 hours of effort, sometimes within a 24-hour window) and submit it as a zip. Clean, modular, extensible code is the goal.

What is the DSA bar?

High. You typically face three medium-to-hard problems and need to fully solve at least two, all test cases passing, to advance.

Are the rounds eliminatory?

Yes. Each round is a gate, so you must clear one to reach the next.
