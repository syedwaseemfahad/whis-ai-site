Infosys Interview Guide (2026)

Infosys hires via an online assessment then technical + HR interviews; SP/DSE run a pure coding test.

The hiring process

System Engineer uses aptitude + pseudocode + verbal; Specialist Programmer / Digital Specialist Engineer use a 3-problem coding test. Then a technical interview and HR.

RoundFormatWhat's tested
Online assessment (SE)~2–3 hrsAptitude, logical/pseudocode, verbal
Coding test (SP/DSE)~3 hrs3 DSA problems with sectional cutoffs (Java/Python/C++/C)
Technical interview30–45 minOOP, DBMS/SQL, OS, CN, live coding for SP/PP, project
HR15–20 minCommunication, motivation, flexibility

Process and cutoffs vary by drive and change over time — always confirm on the official careers page.

What to master

  • Pseudocode output tracing
  • DSA: arrays, strings, trees, sorting, complexity (+ DP/graphs for SP/DSE)
  • OOP with real examples, DBMS normalization
  • Project depth

Eligibility

Typically 60% / 6.0+ throughout with no active backlogs (varies by drive/batch).

Your prep plan

2-week plan

  • Days 1–3: aptitude + pseudocode tracing
  • Days 4–9: DSA (arrays→strings→trees; DP/graphs for SP/DSE)
  • Days 10–11: OOP/DBMS/OS/CN + project
  • Days 12–14: mocks + HR

2-day crash plan

  • Day 1: pseudocode + 12 DSA problems
  • Day 2: CS fundamentals + project + HR

FAQ

How is SP vs DSE decided?

The same coding test decides both: a high score routes to Specialist Programmer, a moderate score to Digital Specialist Engineer.

What are InfyTQ and HackWithInfy?

Alternate routes — InfyTQ certification and the HackWithInfy coding contest can fast-track you to SP/PP roles.

How much DSA should I prep for SP/DSE?

Weight heavily toward DSA (roughly 70%), including DP and graphs.
