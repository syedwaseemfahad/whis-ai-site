What Whis‑AI does
✅ Easy fixes ✅ First‑time setup ✅ Shortcuts cheat‑sheet
Whis‑AI is an intelligent thought partner for technical interviews. It runs as a small desktop overlay on macOS and Windows and helps you structure answers, explain clearly, and stay calm under pressure.
Start here (new users)
If Whis‑AI doesn’t work, it’s almost always due to:
  1. Missing permissions
  2. Using the wrong shortcut
  3. Launching incorrectly on macOS (from Downloads instead of Applications)
Tip: Go top‑to-bottom once — it resolves ~99% of first‑time issues.
Phase 1 — Installation
macOS — do this exactly
  1. Download Whis.app
  2. Open Downloads
  3. Drag Whis.app → Applications
  4. Open from Applications (not Downloads)
Important: Opening from Downloads can break permissions.
Windows — installation
  1. Run the downloaded .exe
  2. If SmartScreen shows “Protected your PC” → More info → Run anyway
Note: SmartScreen warnings are common for newer desktop apps.
Phase 2 — Permissions
If Whis‑AI doesn’t hear or respond, permissions are missing.
macOS (System Settings → Privacy & Security)
  • Microphone — allows Whis‑AI to hear the interviewer
  • Accessibility — keeps the overlay on top
  • Screen Recording — required for screenshot questions
After changing permissions: close and reopen Whis‑AI.
Quick checks
  • Can’t hear audio → check Microphone
  • Screenshot doesn’t work → check Screen Recording
  • Overlay goes behind windows → check Accessibility
Phase 3 — Shortcuts (save this)
Action macOS Windows
Hide / Show ⌘ + \ Ctrl + \
Send ⌘ + Enter Ctrl + Enter
Clear ⌘ + ⌫ Ctrl + ⌫
Quit App ⌘ + Q Ctrl + Q
Move Window ⌘ + Arrow Keys Ctrl + Arrow Keys
If the app “disappears” — you probably hid it. Use Hide / Show again.
Phase 4 — Screenshare & Stealth
✅ Stealth Mode is ON for all plans, including Free. Whis-AI is blocked at the OS level — invisible in screenshares, screenshots, and screen recordings.
Hide shortcut — ⌘/Ctrl + H
Instantly fades the app from your own view. Use this if someone is physically near you or glancing at your screen. Press again to bring it back.
Screenshare & screenshot invisibility
Whis-AI does not appear in Zoom/Teams/Meet live shares, recordings, or even regular screenshots. Share your Entire Screen confidently — the interviewer literally cannot capture it.
Screenshot for input (⌘/Ctrl + J)
When you use the screenshot shortcut to send a question to Whis-AI, the app briefly hides itself before capturing so it is never included in the captured image.
Phase 5 — Using Whis‑AI (end‑to-end)
Before the interview (5 minutes)
  1. Open Whis‑AI and sign in
  2. Open Manage Contexts → add your Resume + (optional) Job Description
  3. Turn Crisp Mode ON (recommended for first interviews)
  4. Test Mic ON + take one Screenshot
Mic clarity: Whis listens to system / computer output audio (interviewer) only — it does not capture your mic / voice. If you speak and don’t see yourself being transcribed, that’s expected.
Option 1: Live Listening
  1. Press Mic shortcut (⌘/Ctrl + L)
  2. Mic icon turns red & pulses
  3. Pause 1–2 seconds after interviewer finishes
Option 2: Manual Chat
Type prompts like: “Answer in STAR”, “Explain step‑by‑step”, “Be concise”, then Send (⌘/Ctrl + Enter).
Option 3: Screenshot OCR
Press Screenshot shortcut (⌘/Ctrl + J) to instantly capture and analyze on-screen questions.
Send button tip: The Send button (and ⌘/Ctrl + Enter) is common for all 3 inputs — manual typing, live listening (voice → text), and screenshot OCR.
Avoid these mistakes: forgetting Mic ON, wrong Context, reading answers word‑for‑word, forgetting Hide shortcut.
Phase 6 — Context & Crisp Mode
Context Manager
Upload/paste your Resume and Job Description. This makes answers sound like you and improves relevance.
Crisp Mode
Crisp ON → faster reading, shorter answers. Crisp OFF → deeper explanations.
Phase 7 — Trial sessions & closing
  • Trial timer appears at the top during a session
  • Turns red in the last minute
  • Click Stop (X) to end early
Closing tip: Closing the window ≠ exiting the app. Use the app’s top‑right X to fully exit.
Still stuck?
If something isn’t working properly, open the Profile menu → click Refresh. If it still doesn’t work, close the app and reopen it from the Applications folder. No other steps are needed.

Welcome to Whis-AI

Your silent interview copilot.

This runs invisibly in the background. Understand the mechanics and shortcuts below to perform flawlessly under pressure.

Auto Mode

The passive observer.

Listens strictly to the interviewer via System Audio. Do not click anything. When they finish asking, simply press Cmd/Ctrl + Enter.

Whis-AI silently captures your screen, pairs it with the audio, and streams the perfect technical answer.

Manual Mode

Absolute, explicit control.

  • Cmd/Ctrl + L: Toggle Mic to start/stop listening.
  • Cmd/Ctrl + E: Instantly attach a screen capture.

Press Cmd/Ctrl + Enter to send.

Stealth & Movement

Discretion is key.

Press Cmd/Ctrl + \ to instantly hide or show the app. It vanishes without a trace.

Hold Cmd/Ctrl and press the Arrow Keys to rapidly shift the window out of your way.

The Context Engine

Sound like you.

Click your Profile Icon and open the Context Manager. Add your Resume and Job Description.

Whis-AI will dynamically generate answers based strictly on your exact historical frameworks and projects.

Crisp Mode

Control reading speed.

Toggle the target icon in the input bar.

ON: Short, punchy, heavily bulleted hints to glance at while maintaining eye contact.

OFF: Massive, deeply technical, multi-paragraph architectural explanations.

Setup & Clearing

Final preparation.

Mac Users: You must allow Screen Recording, Mic, and Accessibility in System Settings to function.

Press Cmd/Ctrl + Del anytime to clear the memory and start fresh.

You are ready. Good luck.
